## 1. main.cpp - 程序入口

**位置**: `/rpcs3/main.cpp`

这是整个 RPCS3 程序的入口点，仅有 10 行左右代码。

### 源代码分析

```cpp
#include "stdafx.h"
#include "main_application.h"
#include "headless_application.h"

int main(int argc, char** argv)
{
    // 检查是否以无头模式运行（命令行模式）
    for (int i = 1; i < argc; i++)
    {
        if (std::string_view(argv[i]) == "--no-gui")
        {
            // 创建无头应用
            headless_application app(argc, argv);
            return app.exec();
        }
    }

    // 默认：创建带 GUI 的应用
    main_application app(argc, argv);
    return app.exec();
}
```

### 学习要点

1. **命令行参数处理**: 使用 `argc` 和 `argv`
2. **C++17 std::string_view**: 高效的字符串视图，无需拷贝
3. **条件创建对象**: 根据参数选择应用类型
4. **RAII**: 应用对象在栈上创建，自动析构

### 应用类型

**main_application** (带 GUI):
- 基于 Qt6
- 完整的图形界面
- 游戏列表、设置、调试器等

**headless_application** (无头模式):
- 命令行模式
- 用于自动化测试
- 服务器环境

## 2. rpcs3.cpp - 主应用逻辑

**位置**: `/rpcs3/rpcs3.cpp`

这个文件包含模拟器的核心启动逻辑。

### 关键函数分析

#### Boot 函数 - 启动游戏

```cpp
game_boot_result Emulator::BootGame(
    const std::string& path,
    const std::string& title_id,
    bool direct,
    bool add_only,
    cfg_mode config_mode,
    const std::string& config_path)
{
    // 1. 验证路径
    if (!fs::exists(path))
    {
        sys_log.error("Boot failed: file not found (%s)", path);
        return game_boot_result::invalid_file_or_folder;
    }

    // 2. 加载配置
    if (!config_path.empty())
    {
        // 使用自定义配置
        g_cfg.from_string(fs::file(config_path).to_string());
    }

    // 3. 初始化虚拟文件系统
    const std::string emu_dir = GetEmuDir();
    vfs::mount("/dev_hdd0", fmt::format("%s/dev_hdd0", emu_dir));
    vfs::mount("/dev_flash", fmt::format("%s/dev_flash", emu_dir));
    vfs::mount("/dev_usb000", fmt::format("%s/dev_usb000", emu_dir));

    // 4. 加载可执行文件
    fs::file elf_file(path);

    ppu_exec_object ppu_exec;
    ppu_prx_object ppu_prx;
    spu_exec_object spu_exec;
    arm_exec_object arm_exec;

    if (ppu_exec.open(elf_file) == elf_error::ok)
    {
        // PPU 可执行文件
        m_title_id = ppu_exec.get_title_id();
        m_cat = "DG";  // Disc Game
    }
    else if (ppu_prx.open(elf_file) == elf_error::ok)
    {
        // PPU PRX (共享库)
        m_cat = "GD";
    }
    else if (spu_exec.open(elf_file) == elf_error::ok)
    {
        // SPU 可执行文件
        m_cat = "SG";
    }
    else
    {
        sys_log.error("Invalid or unsupported file format");
        return game_boot_result::invalid_file_or_folder;
    }

    // 5. 设置线程池大小
    const u32 thread_count = g_cfg.core.preferred_spu_threads;
    g_fxo->init<named_thread_group>("SPU Thread Group", thread_count);

    // 6. 初始化 PPU 模块
    if (!ppu_load_exec(ppu_exec))
    {
        sys_log.error("Failed to load PPU executable");
        return game_boot_result::firmware_missing;
    }

    // 7. 初始化 RSX
    g_fxo->init<named_thread<rsx::thread>>("RSX Thread");

    // 8. 开始执行
    if (auto ppu = idm::get<named_thread<ppu_thread>>(ppu_thread::id_base))
    {
        ppu->state -= cpu_flag::stop;
        ppu->notify();
    }

    // 9. 游戏启动成功
    m_status = system_state::running;
    return game_boot_result::no_errors;
}
```

### 学习要点

1. **错误处理**: 每步都检查错误，提前返回
2. **资源管理**: 使用 RAII 和智能指针
3. **虚拟文件系统**: 将 PS3 路径映射到主机路径
4. **多线程**: 创建 PPU、SPU、RSX 线程
5. **全局对象**: `g_cfg`（配置）、`g_fxo`（固定对象）

## 3. util/atomic.hpp - 原子操作

**位置**: `/rpcs3/util/atomic.hpp`

这是 RPCS3 的原子操作核心，封装了无锁并发编程的基础设施。

### atomic_t<T> 模板类

```cpp
template <typename T>
class atomic_t
{
    // 确保 T 是可平凡复制的
    static_assert(std::is_trivially_copyable_v<T>);

    // 底层存储
    alignas(T) mutable std::atomic<T> m_data;

public:
    // 默认构造
    atomic_t() noexcept = default;

    // 值构造
    atomic_t(const T& value) noexcept
        : m_data(value)
    {
    }

    // 原子加载
    T load() const noexcept
    {
        return m_data.load(std::memory_order_seq_cst);
    }

    // 原子存储
    void store(const T& value) noexcept
    {
        m_data.store(value, std::memory_order_seq_cst);
    }

    // 原子交换
    T exchange(const T& value) noexcept
    {
        return m_data.exchange(value, std::memory_order_seq_cst);
    }

    // 比较并交换
    bool compare_exchange(T& expected, const T& desired) noexcept
    {
        return m_data.compare_exchange_strong(
            expected, desired,
            std::memory_order_seq_cst,
            std::memory_order_seq_cst);
    }

    // 比较并交换（测试版本）
    bool compare_and_swap_test(const T& old_value, const T& new_value) noexcept
    {
        T expected = old_value;
        return compare_exchange(expected, new_value);
    }

    // 原子加法
    T fetch_add(const T& value) noexcept
    {
        return m_data.fetch_add(value, std::memory_order_seq_cst);
    }

    // 原子减法
    T fetch_sub(const T& value) noexcept
    {
        return m_data.fetch_sub(value, std::memory_order_seq_cst);
    }

    // 原子与
    T fetch_and(const T& value) noexcept
    {
        return m_data.fetch_and(value, std::memory_order_seq_cst);
    }

    // 原子或
    T fetch_or(const T& value) noexcept
    {
        return m_data.fetch_or(value, std::memory_order_seq_cst);
    }

    // 原子异或
    T fetch_xor(const T& value) noexcept
    {
        return m_data.fetch_xor(value, std::memory_order_seq_cst);
    }

    // 隐式转换为 T
    operator T() const noexcept
    {
        return load();
    }

    // 赋值运算符
    T operator=(const T& value) noexcept
    {
        store(value);
        return value;
    }

    // 前置递增
    T operator++() noexcept
    {
        return fetch_add(1) + 1;
    }

    // 后置递增
    T operator++(int) noexcept
    {
        return fetch_add(1);
    }

    // 复合赋值运算符
    T operator+=(const T& value) noexcept
    {
        return fetch_add(value) + value;
    }

    T operator-=(const T& value) noexcept
    {
        return fetch_sub(value) - value;
    }

    T operator&=(const T& value) noexcept
    {
        return fetch_and(value) & value;
    }

    T operator|=(const T& value) noexcept
    {
        return fetch_or(value) | value;
    }

    T operator^=(const T& value) noexcept
    {
        return fetch_xor(value) ^ value;
    }
};
```

### 内存顺序

RPCS3 默认使用 `std::memory_order_seq_cst`（顺序一致性），这是最强的内存顺序保证：

```cpp
// 可用的内存顺序（从弱到强）：
// - memory_order_relaxed: 无同步或顺序保证
// - memory_order_acquire: 获取语义
// - memory_order_release: 释放语义
// - memory_order_acq_rel: 获取-释放
// - memory_order_seq_cst: 顺序一致性（默认）
```

### 使用示例

```cpp
// 创建原子变量
atomic_t<u32> counter{0};

// 线程 A
counter++;              // 原子递增
counter += 10;          // 原子加法

// 线程 B
u32 value = counter;    // 原子读取
counter = 100;          // 原子写入

// 线程 C
u32 old = counter.fetch_add(5);  // 获取旧值并加 5

// CAS (Compare-And-Swap)
u32 expected = 100;
if (counter.compare_exchange(expected, 200))
{
    // 成功：counter 从 100 变为 200
}
else
{
    // 失败：expected 被更新为 counter 的当前值
}
```

### 学习要点

1. **原子性**: 操作要么完全执行，要么不执行
2. **无锁编程**: 不使用互斥锁，性能更好
3. **内存顺序**: 控制操作的可见性
4. **CAS**: 无锁算法的基础
5. **操作符重载**: 使原子操作像普通变量一样使用

## 4. Emu/System.h/cpp - 模拟器系统

**位置**: `/rpcs3/Emu/System.h`, `/rpcs3/Emu/System.cpp`

模拟器的核心系统类。

### 系统状态枚举

```cpp
enum class system_state : u32
{
    stopped,      // 停止
    running,      // 运行中
    paused,       // 暂停
    ready,        // 准备就绪
    frozen,       // 冻结（保存状态）
};
```

### Emulator 类（简化）

```cpp
class Emulator final
{
public:
    // 单例模式
    static Emulator& GetInstance()
    {
        static Emulator instance;
        return instance;
    }

private:
    // 系统状态
    atomic_t<system_state> m_status{system_state::stopped};

    // 标题 ID
    std::string m_title_id;

    // 类别
    std::string m_cat;

    // 路径
    std::string m_path;

public:
    // 启动游戏
    game_boot_result BootGame(
        const std::string& path,
        const std::string& title_id = "",
        bool direct = false,
        bool add_only = false,
        cfg_mode config_mode = cfg_mode::custom,
        const std::string& config_path = "");

    // 暂停/恢复
    void Pause();
    void Resume();

    // 停止
    void Stop();

    // 获取状态
    system_state GetStatus() const
    {
        return m_status.load();
    }

    // 是否运行中
    bool IsRunning() const
    {
        return m_status == system_state::running;
    }

    // 是否暂停
    bool IsPaused() const
    {
        return m_status == system_state::paused;
    }

    // 是否停止
    bool IsStopped() const
    {
        return m_status == system_state::stopped;
    }

    // 获取标题 ID
    const std::string& GetTitleID() const
    {
        return m_title_id;
    }

    // 获取类别
    const std::string& GetCat() const
    {
        return m_cat;
    }

    // 获取路径
    const std::string& GetPath() const
    {
        return m_path;
    }

private:
    // 私有构造函数（单例）
    Emulator() = default;

    // 禁止拷贝
    Emulator(const Emulator&) = delete;
    Emulator& operator=(const Emulator&) = delete;
};

// 全局访问点
inline Emulator& Emu = Emulator::GetInstance();
```

### 使用示例

```cpp
// 启动游戏
auto result = Emu.BootGame("/path/to/game.self");

if (result == game_boot_result::no_errors)
{
    // 游戏启动成功
    while (Emu.IsRunning())
    {
        // 主循环
        std::this_thread::sleep_for(16ms);  // ~60 FPS
    }
}

// 暂停游戏
if (Emu.IsRunning())
{
    Emu.Pause();
}

// 恢复游戏
if (Emu.IsPaused())
{
    Emu.Resume();
}

// 停止游戏
Emu.Stop();
```

### 学习要点

1. **单例模式**: 全局唯一实例
2. **状态机**: 使用枚举管理状态
3. **原子状态**: 多线程安全的状态访问
4. **RAII**: 资源自动管理

## 5. Emu/IdManager.h - ID 管理器

**位置**: `/rpcs3/Emu/IdManager.h`

ID 管理器负责分配和管理所有运行时对象的 ID。

### 核心概念

```cpp
// ID 管理器命名空间
namespace idm
{
    // 创建对象并返回 ID
    template <typename T, typename... Args>
    u32 make(Args&&... args)
    {
        // 创建对象
        auto ptr = std::make_shared<T>(std::forward<Args>(args)...);

        // 分配 ID
        const u32 id = allocate_id<T>();

        // 存储对象
        g_map[id] = std::static_pointer_cast<void>(ptr);

        return id;
    }

    // 通过 ID 获取对象
    template <typename T>
    std::shared_ptr<T> get(u32 id)
    {
        auto it = g_map.find(id);

        if (it == g_map.end())
        {
            return nullptr;  // 对象不存在
        }

        return std::static_pointer_cast<T>(it->second);
    }

    // 删除对象
    template <typename T>
    bool remove(u32 id)
    {
        auto it = g_map.find(id);

        if (it == g_map.end())
        {
            return false;  // 对象不存在
        }

        g_map.erase(it);
        return true;
    }

    // 遍历所有对象
    template <typename T, typename F>
    void select(F&& func)
    {
        for (auto& [id, obj] : g_map)
        {
            if (auto ptr = std::dynamic_pointer_cast<T>(obj))
            {
                func(id, *ptr);
            }
        }
    }

    // 检查对象是否存在
    template <typename T>
    bool check(u32 id)
    {
        return get<T>(id) != nullptr;
    }

private:
    // ID 到对象的映射
    static std::unordered_map<u32, std::shared_ptr<void>> g_map;

    // ID 分配器
    template <typename T>
    static u32 allocate_id()
    {
        static u32 g_id_counter = T::id_base;
        return g_id_counter++;
    }
};
```

### 使用示例

```cpp
// 创建 PPU 线程
u32 thread_id = idm::make<named_thread<ppu_thread>>(
    "Main Thread", 1000, 0x10000);

// 获取线程
auto thread = idm::get<named_thread<ppu_thread>>(thread_id);

if (thread)
{
    // 使用线程
    thread->state += cpu_flag::suspend;
}

// 遍历所有 PPU 线程
idm::select<named_thread<ppu_thread>>([](u32 id, ppu_thread& ppu)
{
    sys_log.notice("Thread 0x%x: pc=0x%x", id, ppu.pc);
});

// 删除线程
idm::remove<named_thread<ppu_thread>>(thread_id);

// 检查是否存在
if (idm::check<named_thread<ppu_thread>>(thread_id))
{
    // 线程存在
}
```

### 学习要点

1. **模板编程**: 泛型对象管理
2. **类型擦除**: 使用 `void*` 存储任意类型
3. **类型安全转换**: `std::static_pointer_cast` 和 `std::dynamic_pointer_cast`
4. **ID 范围**: 每种类型有自己的 ID 起始范围（`id_base`）
5. **线程安全**: 实际实现中有锁保护

## 🎓 总结

### C++ 核心概念在 RPCS3 中的应用

| 概念 | 应用 | 示例文件 |
|------|------|----------|
| **模板** | 泛型编程、类型安全 | atomic.hpp, IdManager.h |
| **RAII** | 资源管理 | File.h, Thread.h |
| **智能指针** | 内存管理 | IdManager.h, System.cpp |
| **原子操作** | 无锁并发 | atomic.hpp, Thread.h |
| **虚函数** | 多态 | file_base, GSRender |
| **单例模式** | 全局访问 | System.h |
| **操作符重载** | 语法糖 | atomic_t, bit_set |
| **完美转发** | 参数传递 | IdManager::make |

### 学习建议

1. **从简单到复杂**: main.cpp → System.h → IdManager.h → atomic.hpp
2. **理解设计模式**: 单例、工厂、观察者等
3. **掌握并发编程**: 原子操作、内存顺序、线程安全
4. **熟悉现代 C++**: C++17/20 特性的应用
5. **调试实践**: 使用调试器逐步执行代码
