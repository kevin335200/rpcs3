## 功能概述
支持三阶段（初始化、使用、析构）并发访问的互斥锁实现。

## 主要内容

### 核心概念
- 使用32位原子值存储状态和初始化位
- 初始化位 (0x80000000): 表示已初始化
- 低31位: 读者计数

### 锁类型
1. **init_lock**: 初始化锁
   - 独占初始化权
   - 支持强制重置
2. **access_lock**: 访问锁
   - 共享读取权（仅在已初始化时）
3. **reset_lock**: 重置锁
   - 独占析构权

### 主要方法
- `init()`: 获取初始化锁
- `init_always()`: 无条件初始化（支持重置回调）
- `reset()`: 获取重置锁
- `access()`: 获取访问锁
- `wait_for_initialized()`: 等待初始化完成

## 代码分析

### 状态机设计
```
State 0: 未初始化，无锁定
State > 0 & < init_bit: 已初始化，有访问者
State >= init_bit: 初始化中
```

### 等待机制
使用原子操作的等待/通知机制协调多个线程。
