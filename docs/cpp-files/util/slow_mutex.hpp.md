## 功能概述
轻量级互斥锁实现，仅占用1字节，用于不频繁竞争的场景。

## 主要内容

### 设计
- 单字节原子存储
- 不使用自旋等待（悲观设计）
- 低7位: 等待者计数
- 高位(0x80): 信号标志

### 核心方法
- `lock()`: 获取锁
  - 递增等待者计数
  - 等待信号
- `try_lock()`: 非阻塞获取
- `unlock()`: 释放锁
  - 递减等待者计数
  - 设置信号并通知

### 特殊方法
- `is_free()`: 检查是否空闲
- `lock_unlock()`: 用于等待其他线程完成

## 代码分析

### 溢出处理
```cpp
if ((val & 0x7f) == 0x7f) // 等待者计数溢出
    m_value.wait(0x7f);
```

### 通知机制
- `notify_one(0x80)`: 通知等待者
- `notify_one(0x7f)`: 通知溢出恢复
