## 功能概述
定义128位向量类型 `v128`，提供多种访问方式和构造函数，支持向量数据的灵活解释和操作。

## 主要内容

### 核心类型
- `v128`: 16字节对齐的128位向量并集
- `Vector128<T>`: 概念定义（大小为16字节的平凡类型）
- `masked_array_t<T, N, M>`: 掩码数组用于字节序交换

### 数据访问方式
- **按字节**: `_bytes[]`, `_chars[]`, `u8r[]`, `s8r[]`
- **按16位**: `_u16[]`, `_s16[]`, `u16r[]`, `s16r[]`
- **按32位**: `_u32[]`, `_s32[]`, `u32r[]`, `s32r[]`
- **按64位**: `_u64[]`, `_s64[]`, `u64r[]`, `s64r[]`
- **浮点**: `_f[]`(单精度), `_d[]`(双精度), `fr[]`, `dr[]`
- **128位**: `_u`, `_s`(128位整数)

### 静态构造函数
- `from64(u64, u64)`: 从两个64位值构造
- `from64r()`: 反向from64
- `from64p(u64)`: 从单个64位值(复制到两个部分)
- `from32(u32, u32, u32, u32)`: 从四个32位值构造
- `from32r()`: 反向from32
- `from32p(u32)`: 从单个32位值(复制到四部分)
- `fromf32p(f32)`: 从浮点值构造
- `from16p(u16)`: 16位值的向量构造
- `from8p(u8)`: 8位值的向量构造(memset)
- `undef()`: 未初始化向量
- `loadu()`: 从指针非对齐加载
- `storeu()`: 向指针非对齐存储

### 向量操作
- **位运算**: `operator|()`, `operator&()`, `operator^()`, `operator~()`
- **比较**: `operator==()`
- **清空**: `clear()`

## 代码分析

### 掩码数组实现
```cpp
template <typename T, usz N, usz M>
struct masked_array_t {
    T m_data[N];

    T& operator[](usz index) {
        return m_data[index ^ M];
    }
};

// 用于字节序自适应
template <typename T, usz N = 16 / sizeof(T)>
using normal_array_t = masked_array_t<T, N,
    std::endian::little == std::endian::native ? 0 : N - 1>;
```

这种方法在运行时自动适应字节序，避免显式的转换代码。

### Serialization支持
```cpp
ENABLE_BITWISE_SERIALIZATION;
```
标记 `v128` 可以通过位复制进行序列化。

### 哈希支持
```cpp
template <>
struct std::hash<v128> {
    usz operator()(const v128& key) const {
        return key._u64[0] + key._u64[1];
    }
};
```
提供简单哈希函数用于容器。

### 概念约束
```cpp
template <typename T>
concept Vector128 = (sizeof(T) == 16) && (std::is_trivial_v<T>);
```
确保只有16字节的平凡类型才能转换为v128。

## 学习要点

### 类型安全的位转换
1. **概念约束**: 确保只有合适的类型能转换
2. **constexpr转换**: 支持编译期转换
3. **bit_cast**: 使用 `std::bit_cast` 实现类型安全的位转换

### 字节序适应设计
1. **编译期检测**: 使用 `std::endian` 检测字节序
2. **掩码数组**: 通过索引掩码自动适应
3. **两倍存储**: 同时提供normal和reversed访问

### 向量类型的多视图模式
- 一个物理存储，多种逻辑视图
- 支持从u8到u64的各种整数类型视图
- 支持浮点视图
- 零开销抽象

### 高效构造和加载
```cpp
// 非对齐加载
static v128 loadu(const void* ptr, usz index = 0) {
    v128 ret;
    std::memcpy(&ret, static_cast<const u8*>(ptr) + index * sizeof(v128),
                sizeof(v128));
    return ret;
}
```
避免对齐要求，适合任意内存位置。

### Union用于类型双关
这种模式允许同一数据以不同类型解释，但需要谨慎的字节序处理。
