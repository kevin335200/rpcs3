## 功能概述
提供指针类型强制转换工具，用于绕过严格的类型检查。使用内联汇编确保操作的安全性。

## 主要内容

### 核心函数
- `utils::bless<T, U>(U* ptr) -> T*`: 指针类型转换

### 实现方式
- **MSVC**: 简单强制转换
- **x86_64**: 内联汇编 `movq`
- **ARM64**: 内联汇编 `mov`

## 学习要点

### 不安全指针转换
- 使用内联汇编避免编译器优化
- 标记为 `[[nodiscard]]` 强制使用结果
- 应谨慎使用
