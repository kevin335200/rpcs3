## 🎯 功能概述

SHA-256 (Secure Hash Algorithm 2, 256-bit) 生成 256 位（32 字节）的密码散列值。同时支持 SHA-224（224 位输出）。特点：
- 当前推荐使用的安全散列算法
- 支持 SHA-256 和 SHA-224 两种模式
- 增量处理支持
- 高安全性和广泛应用

## 💻 代码分析

### SHA-256 算法流程

#### 消息扩展
```
W[0..15] = 消息块（16 个 32 位字）
W[16..63] = 生成的消息队列

W[t] = σ1(W[t-2]) + W[t-7] + σ0(W[t-15]) + W[t-16]

其中：
σ0(x) = RIGHTROTATE(x,7) ^ RIGHTROTATE(x,18) ^ RIGHTSHIFT(x,3)
σ1(x) = RIGHTROTATE(x,17) ^ RIGHTROTATE(x,19) ^ RIGHTSHIFT(x,10)
```

#### 主压缩循环
```
初始化：
a = H[0]  ...  h = H[7]

主循环（64 轮）：
T1 = h + Σ1(e) + CH(e,f,g) + K[i] + W[i]
T2 = Σ0(a) + MAJ(a,b,c)
h = g
g = f
f = e
e = d + T1
d = c
c = b
b = a
a = T1 + T2

其中：
Σ0(x) = RIGHTROTATE(x,2) ^ RIGHTROTATE(x,13) ^ RIGHTROTATE(x,22)
Σ1(x) = RIGHTROTATE(x,6) ^ RIGHTROTATE(x,11) ^ RIGHTROTATE(x,25)
CH(x,y,z) = (x & y) ^ (~x & z)
MAJ(x,y,z) = (x & y) ^ (x & z) ^ (y & z)
```

#### 最后步骤
```cpp
H[0] = a + H[0]
H[1] = b + H[1]
// ... 更新所有 8 个状态字
```

## 使用示例

```cpp
// 简单哈希
unsigned char data[] = "Hello, World!";
unsigned char hash[32];
mbedtls_sha256_ret( data, sizeof(data)-1, hash, 0 );

// 大文件哈希
mbedtls_sha256_context ctx;
mbedtls_sha256_init( &ctx );
mbedtls_sha256_starts_ret( &ctx, 0 );

FILE *f = fopen( "largefile.bin", "rb" );
char buffer[4096];
while ( fread( buffer, 1, sizeof(buffer), f ) > 0 ) {
    mbedtls_sha256_update_ret( &ctx, (unsigned char*)buffer, 4096 );
}
fclose( f );

unsigned char hash[32];
mbedtls_sha256_finish_ret( &ctx, hash );
mbedtls_sha256_free( &ctx );

// 转换为十六进制字符串
for ( int i = 0; i < 32; i++ ) {
    printf( "%02x", hash[i] );
}
```
