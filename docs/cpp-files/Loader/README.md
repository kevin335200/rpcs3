# RPCS3 Loader 模块文档

RPCS3 Loader 模块负责处理各种 PlayStation 文件格式的加载和解析。本文档介绍了模块中的所有关键文件及其功能。

## 模块概述

Loader 模块是 RPCS3 的核心组件之一，支持多种文件格式的解析和加载：

- **ELF**: 可执行文件格式（PS3、PS2、PSP 等）
- **PSF/SFO**: PlayStation 参数文件（游戏元数据）
- **PUP**: PlayStation 更新包（固件）
- **TAR**: TAR 存档格式
- **TRP**: Trophy 包（奖杯数据）
- **TROPUSR**: Trophy 用户数据
- **MSELF**: 多文件自解包格式
- **DISC**: 光盘类型检测

## 文件详细列表

### 1. ELF 加载器 - [ELF.md](./ELF.md)

**文件**: `ELF.h`, `ELF.cpp`

**功能**:
- 解析 ELF（Executable and Linkable Format）可执行文件
- 支持多种架构：PPU (PPC64)、SPU、ARM、MIPS
- 支持大端和小端字节序
- 支持 32-bit 和 64-bit 地址空间
- 读取程序头、节头和相关数据
- 支持 ELF 文件的保存和重建

**关键特性**:
- 模板化设计支持不同的架构和字节序
- 节数据优化，使用 span 避免重复存储
- 完整的错误检查和验证
- 支持 PS3 特定的文件类型（PRX、REL）

**典型用途**:
- 加载 PS3 可执行程序 (EBOOT.BIN)
- 加载 PS3 动态库 (*.PRX)
- 加载 SPU 程序
- 支持向下兼容 PSP、PS Vita 等

---

### 2. PSF 加载器 - [PSF.md](./PSF.md)

**文件**: `PSF.h`, `PSF.cpp`

**功能**:
- 读写 SFO（System File Object）文件
- 存储游戏元数据（标题、版本、类别等）
- 支持整数、字符串和二进制数组三种数据类型
- 完全兼容 PlayStation 系列（PS1、PS2、PS3、PSP、PS Vita）

**关键特性**:
- 类型化的键值存储（registry）
- 灵活的条目类型支持
- 完整的数据验证和错误处理
- 类别验证确保文件合法性

**常见字段**:
- TITLE: 应用标题
- TITLE_ID: 6 字符的游戏 ID
- CATEGORY: 应用类别（GD=游戏、DG=演示等）
- VERSION: 应用版本号
- PS3_SYSTEM_VER: 最低系统版本

**典型用途**:
- 读取游戏信息 (PARAM.SFO)
- 更新游戏元数据
- 验证游戏有效性

---

### 3. PUP 加载器 - [PUP.md](./PUP.md)

**文件**: `PUP.h`, `PUP.cpp`

**功能**:
- 解析 PS3 固件更新包 (PUP 文件)
- 验证每个固件块的 SHA1-HMAC
- 支持提取固件中的单个文件块
- 确保固件的完整性和真实性

**关键特性**:
- SHA1-HMAC 基于官方 Sony 密钥验证
- 整数溢出防护
- 详细的错误信息
- 流式文件访问

**文件结构**:
- PUP 头部：版本、大小、块数量
- 文件表：每个块的偏移和大小
- 哈希表：每个块的 SHA1-HMAC
- 块数据

**典型用途**:
- 验证固件完整性
- 提取固件数据
- 支持固件更新流程

---

### 4. TAR 加载器 - [TAR.md](./TAR.md)

**文件**: `TAR.h`, `TAR.cpp`

**功能**:
- 解析 TAR（Tape Archive）存档格式
- 支持从文件系统和内存流读取
- 列表、提取和创建 TAR 存档
- 支持加密 TAR 文件解密
- 异步多线程文件提取优化

**关键特性**:
- ustar 格式支持（POSIX 标准）
- 八进制时间戳处理
- 递归目录遍历和存档创建
- VFS 虚拟文件系统集成
- 自动时间戳恢复

**文件结构**:
- TAR 头部（512 字节）：文件名、大小、权限、时间戳
- 文件数据：512 字节对齐
- 文件头重复，最后两个 512 字节全零表示结束

**典型用途**:
- 提取固件内容
- 安装游戏资源
- 归档游戏文件

---

### 5. TROPUSR 加载器 - [TROPUSR.md](./TROPUSR.md)

**文件**: `TROPUSR.h`, `TROPUSR.cpp`

**功能**:
- 管理 PS3 Trophy（奖杯）用户数据
- 读写 TROPUSR.DAT 文件
- 从配置文件生成新的奖杯数据
- 跟踪奖杯解锁状态和时间戳

**关键特性**:
- 两个数据表：元数据（Table 4）和状态（Table 6）
- 奖杯等级分类（铂金、金、银、铜）
- 时间戳记录解锁时刻
- 铂金奖杯链接机制
- 自动从配置恢复损坏数据

**奖杯结构**:
- Table 4: 奖杯元数据（ID、等级、铂金链接）
- Table 6: 解锁状态（是否解锁、时间戳）

**典型用途**:
- 加载玩家的奖杯进度
- 解锁或锁定奖杯
- 创建新的奖杯数据文件
- 支持奖杯同步功能

---

### 6. TRP 加载器 - [TRP.md](./TRP.md)

**文件**: `TRP.h`, `TRP.cpp`

**功能**:
- 处理 Trophy 包（TRP 文件）安装
- 验证 SHA1 校验和（v2+）
- 管理奖杯文件的原子安装
- 支持条目管理（添加、删除、重命名）

**关键特性**:
- 原子性安装（临时目录策略）
- SHA1 验证确保数据完整性
- 备份现有数据防止丢失
- 错误恢复清理机制

**TRP 结构**:
- 头部：魔数、版本、文件大小、文件计数、SHA1
- 条目表：每个文件的名称、偏移、大小
- 文件数据

**安装流程**:
1. 创建临时目录
2. 备份现有 TROPUSR.DAT
3. 提取 TRP 中的所有文件
4. 删除旧目录
5. 原子重命名临时目录
6. 失败时清理临时文件

**典型用途**:
- 从线上商店安装奖杯包
- 管理本地奖杯文件
- 防止部分安装的数据损坏

---

### 7. MSELF 加载器 - [mself.md](./mself.md)

**文件**: `mself.hpp`, `mself.cpp`

**功能**:
- 解析 MSELF（Multiple SELf）多文件容器
- 提取所有包含的文件
- 验证容器完整性

**关键特性**:
- 简单的固定大小头部和记录
- 快速 O(1) 记录查找
- 完整性检查和边界验证
- 流式提取避免全文件加载

**MSELF 结构**:
- 头部（64 字节）：魔数、版本、总大小、记录数
- 记录表（每个 64 字节）：文件名、偏移、大小
- 文件数据

**典型用途**:
- 提取固件文件
- 解包系统软件
- 支持固件分析

---

### 8. Disc 加载器 - [disc.md](./disc.md)

**文件**: `disc.h`, `disc.cpp`

**功能**:
- 检测光盘类型（PS3、PS2、PS1）
- 定位游戏目录和系统文件
- 支持多代 PlayStation 平台

**光盘类型检测**:
1. **PS3**: 搜索 ELF + PARAM.SFO，验证类别 = "DG"
2. **PS2**: 搜索 SYSTEM.CNF，检查 BOOT2 字段
3. **PS1**: 搜索 SYSTEM.CNF，检查 BOOT 字段

**返回信息**:
- 光盘类型（PS3/PS2/PS1/无效）
- 光盘根目录
- PS3 游戏目录路径

**典型用途**:
- 自动检测游戏平台
- 启动正确的模拟器模式
- 支持混合光盘集合（包含多代游戏）

## 通用概念

### 字节序处理
- **大端 (Big-Endian)**: PowerPC、PS3 使用
- **小端 (Little-Endian)**: x86、ARM 使用
- 模板化方法 `be_t<T>` 和 `le_t<T>` 自动处理转换

### 错误处理
- 使用枚举而非异常
- 详细的日志记录方便调试
- 优雅降级支持多个格式

### 虚拟文件系统 (VFS)
- 统一的文件路径处理
- 支持安全的 VFS 转义
- 允许虚拟挂载和重定向

### 内存优化
- 缓冲区重用减少分配
- Span 和视图避免复制
- 流式处理大文件

## 常见任务

### 加载 PS3 游戏
```
Disc Type Detection (disc)
  ↓ (识别为 PS3)
Load ELF (ELF) + PARAM.SFO (PSF)
  ↓ (提取元数据)
启动游戏
```

### 安装固件
```
Load PUP File (PUP)
  ↓ (验证 HMAC)
Extract TAR (TAR)
  ↓ (解包)
Extract MSELF (MSELF)
  ↓ (提取各个模块)
Install System Software
```

### 管理奖杯
```
Load TRP Package (TRP)
  ↓ (验证 SHA1)
Extract Files (TAR/Files)
  ↓
Load/Create TROPUSR.DAT (TROPUSR)
  ↓ (管理解锁状态)
Save Progress
```
