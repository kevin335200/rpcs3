## 功能概述

AArch64JIT.cpp 是 GHC 栈管理转换通道的实现文件。它实现了 ARM64 上的栈帧保留、函数序幕/收尾生成和尾调用优化，确保 GHC 栈无关执行模型与 C++ ABI 兼容。

## 主要内容

### 核心实现

#### run() 方法
主转换通道入口：
1. 预处理函数获取分析信息
2. 强制尾调用终止符
3. 处理叶子函数特殊情况
4. 为非叶子函数生成栈帧

#### preprocess_function()
函数级别分析：
- 计算指令数量
- 统计外部调用
- 估计栈帧大小
- 识别被修改的寄存器
- 检测叶子函数

#### decode_instruction()
指令级别分析：
- 识别调用指令
- 检测返回指令
- 识别间接调用
- 查找被调用函数信息
- 确定是否需要栈保留

### 函数变换

#### process_leaf_function()
叶子函数优化：
- 识别不调用其他函数的函数
- 跳过栈帧分配
- 保存被修改的寄存器

#### patch_tail_call()
尾调用处理：
- 识别尾调用（函数最后的调用）
- 重用当前栈帧
- 优化寄存器恢复

### 寄存器管理

#### get_base_register_for_call()
查询线程上下文基址寄存器：
- 使用 base_register_lookup 配置
- 确定访问线程状态的寄存器
- 默认使用 x19

### 代码生成

#### 序幕代码 (Prologue)
函数开始时生成：
```
stp x29, x30, [sp, -frame_size]!  ; 保存 FP 和 LR，分配栈
add x29, sp, 0                     ; 设置新的帧指针
stp x19, x20, [sp, #16]           ; 保存被调用者寄存器
...
```

#### 收尾代码 (Epilogue)
函数返回前生成：
```
ldp x19, x20, [sp, #16]           ; 恢复被调用者寄存器
ldp x29, x30, [sp], frame_size    ; 恢复 FP 和 LR，释放栈
ret                                ; 返回
```

## 代码分析

### 栈帧布局

```
High Address
    ┌─────────────────┐
    │   其他栈数据    │
    ├─────────────────┤
sp→ │   被保存寄存器  │
    │   (x19-x28 等)  │
    ├─────────────────┤
    │   局部变量      │
    ├─────────────────┤
x29→│   前帧指针(FP)  │
    │   返回地址(LR)  │
    ├─────────────────┤
    │  调用者栈帧     │
    └─────────────────┘
Low Address
```

### 优化策略

1. **叶子函数**: 无调用 → 无栈帧分配
2. **尾调用**: 最后一个调用 → 栈帧重用
3. **寄存器选择**: 仅保存被修改的寄存器
4. **栈大小估计**: 考虑向量溢出空间

### 复杂性处理

1. **递归函数**: 正确处理自调用
2. **异常处理**: 确保异常处理中的正确栈状态
3. **调试信息**: 生成有效的 DWARF 调试信息
4. **内联优化**: 处理内联调用不破坏栈帧
